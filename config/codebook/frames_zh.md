# 框架标注 Codebook（中文 v1.0，Phase 1）

> 用途：Tagger 分层路由的规则词典/LLM prompt 共享判据；gold set 标注手册。
> 纪律（裁决 B）：本 codebook + gold set 通过 Krippendorff's α ≥ 0.7 前，
> 框架占比数字不得对外展示；输出一律为逐句概率分布，禁止单点硬标签。

## 0. 理论操作化（Entman 四功能 → 可判定的句级判据）

Entman 框架四功能在句级落地为四个可答问题：

1. **问题定义**：句子把什么界定为"问题"？（谁受损/什么有风险）
2. **因果归因**：句子把原因归于谁/什么？（主体+机制）
3. **道德评价**：句子作了好坏/对错判断吗？
4. **对策建议**：句子提出/暗示解决方向吗？

一个句子可以同时激活多个框架（多标签）；都不沾边 → `other`。

## 1. 五框架判据与关键词线索

### 1.1 loss（损失框架）
- **判据**：强调负面后果、损失量、风险敞口、下行；问题定义=受损。
- **线索词**：损失、下滑、萎缩、亏损、裁员、破产、暴跌、承压、恶化、冲击、风险敞口、缩水、折价。
- **正例**：
  1. 出口企业二季度利润缩水三成，订单流失至东南亚。
  2. 关税上调使下游制造业成本承压，中小企业面临倒闭风险。
  3. 该政策落地后，地方财政缺口预计扩大至千亿级。
  4. 房企债务违约蔓延，供应链上游供应商货款回收困难。
  5. 消费者信心指数连续三月下滑，耐用品销售明显萎缩。
- **反例**：
  1. 利润缩水的同时，海外市场份额反而提升。（混合：loss+gain，分布各 ~0.5）
  2. 政府表态将出台纾困措施。（gain/responsibility 方向，非损失陈述）
  3. 分析师预测明年复苏。（gain 预期）

### 1.2 gain（收益框架）
- **判据**：强调正面后果、机会、红利、上行。
- **线索词**：增长、提升、红利、机遇、回暖、盈利、扩张、复苏、利好、加码、超预期。
- **正例**：
  1. 减税政策为中小企业释放千亿红利，市场活力显著回升。
  2. 新能源出口同比增长四成，成为外贸最大亮点。
  3. 降准落地后流动性充裕，机构普遍上调增长预期。
  4. 自贸协定生效，区域贸易成本大幅下降。
  5. 消费券拉动效应显现，节假日零售额超预期。
- **反例**：
  1. 增长主要靠基数效应。（责任归因，gain 弱）
  2. 表面增长难掩结构性问题。（loss 主导）
  3. 增长数据与微观感受背离。（conflict/质疑）

### 1.3 responsibility（责任框架）
- **判据**：因果归因指向具体主体（政府/企业/个人），含问责、担当、失职、呼吁。
- **线索词**：问责、失职、应为、责任在于、归咎、督促、呼吁、担责、整改、监管不力。
- **正例**：
  1. 审计报告指出三部门专项资金使用失范，相关负责人被问责。
  2. 分析认为此轮通胀主要归咎于供给端管理失当。
  3. 学界呼吁央行对资金空转承担监管责任。
  4. 事故调查组认定企业安全投入不足是主因。
  5. 代表委员建议地方政府对烂尾楼处置负起兜底责任。
- **反例**：
  1. 责任保险市场规模扩大。（"责任"为名词术语，非归因）
  2. 事故原因正在调查。（无归因主体）
  3. 企业履约良好。（事实陈述）

### 1.4 conflict（冲突框架）
- **判据**：两个及以上主体间的对立、博弈、争端、对抗叙事。
- **线索词**：争端、制裁、反制、博弈、对抗、摩擦、指控、调查、诉讼、壁垒、升级、交锋。
- **正例**：
  1. 中美就关税清单再度交锋，双方各亮反制筹码。
  2. 欧盟对华电动车反补贴调查升级，中企拟提起诉讼。
  3. 劳资谈判破裂，港口工人宣布罢工。
  4. 两国在汇率问题上相互指责，摩擦面扩大。
  5. 平台与商家费率之争激化，多家商户下架。
- **反例**：
  1. 双方同意继续磋商。（缓和，conflict 弱）
  2. 历史上的贸易战教训。（回顾背景）
  3. 第三方调解取得进展。（resolution 导向）

### 1.5 human_interest（人情味框架）
- **判据**：以个体故事/情感/生活影响切入，微观视角。
- **线索词**：一位、家庭、生计、生存、故事、泪水、坚守、小微企业主、打工人、菜贩。
- **正例**：
  1. 一位做了二十年外贸的老板：这次真的撑不住了。
  2. 房贷利率下调后，一个三口之家每月少还八百元。
  3. 快递站点关闭后，五十六岁分拣员的再就业之路。
  4. 小店店主账本上的三年：从日流水八千到一千二。
  5. 留守老人如何跨越数字鸿沟领取养老金。
- **反例**：
  1. 全国就业数据公布。（宏观统计）
  2. 社保制度改革方案出台。（政策框架）
  3. 该企业家出身草根，如今身家百亿。（人物成功学，非政策叙事）

### 1.6 other（兜底）
- 纯数据播报、程序性公告、与五框架均无关者。例：明天将公布 PMI 数据。

## 2. 标注规则

1. **多标签概率分布**：每句输出 {frame: prob}，Σprob=1；混合句按信息占比分配（如"利润缩水但份额提升" → loss 0.5 / gain 0.5）。
2. **句级而非篇级**：以句子为单位；标题与正文分别标注。
3. **弃权**：文本过短（<8 字）或语义不完整 → {"other": 1.0} + 备注 abstain。
4. **争议处理**：标注分歧 >0.3 时进入仲裁队列，双人复核。
5. **禁用外部知识**：仅依据句面信息；不得用后续事实回填判断。

## 3. Gold Set 流程（裁决 B 测量效度硬门禁）

1. LLM 预标（GLM-5.3，本 codebook 作 system prompt 附件）→ 候选池。
2. 人工复核每条：接受/修正/驳回；目标 500-1000 句。
3. 双人独立标注 ≥200 句 → 计算 Krippendorff's α（按帧 one-vs-rest）。
4. α ≥ 0.7 → 该帧数字方可对外展示；否则回炉修订判据。
5. 标注者只看原始句子，不看任何 LLM 解释（消除锚定偏误）。
